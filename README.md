## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/FrancyelliSilva/python.git
```

2. Acesse a pasta:
```bash
cd python
```

3. Execute qualquer arquivo:
```bash
python nome_do_arquivo.py
```
